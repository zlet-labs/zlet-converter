# Conversion Flow

## Empty state

User opens Converter.

Actions:

- Add files
- Add folder
- Drag & drop

## Loaded state

System shows:

- files;
- detected formats;
- conversion routes;
- output.

## Processing

Statuses:

- Queued
- Converting
- Checking
- Completed
- Review required
- Failed

## Result

User can:

- open output;
- inspect Markdown;
- view quality findings;
- retry conversion.
