# Zlet Converter UI Design

Current approved UI direction.

## Main workflow

Add documents
→ Configure conversion
→ Convert
→ Quality check
→ Review result
→ Export

## Main screens

- Convert Workbench
- Conversion Progress
- Conversion Completed
- Quality Review
- History
- Settings

## Principles

- Local-first
- Light theme first
- Queue-centered workspace
- Visible conversion route
- Clear document states
- No unnecessary dashboards
